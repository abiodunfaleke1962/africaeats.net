# africaeats.net — Dad's Spicy Chicken

Marketing site for **Dad's Spicy Chicken**, an authentic West African family restaurant (Everett, WA).

- **Live site:** https://www.africaeats.net
- **Host:** GitHub Pages (deploy from `main`, root)
- **Custom domain:** `www.africaeats.net` (see `CNAME`)
- **DNS:** Cloudflare

## Editing
The whole site is a single self-contained `index.html` (inline CSS, Google Fonts only — no build step, no dependencies). Edit it directly and commit; GitHub Pages redeploys automatically within ~1 minute.

## Deploy / go-live
See the migration guide provided at setup for the exact GitHub Pages settings and Cloudflare DNS records.
